# 想吃梨儿童美术教务考勤与财务管理系统 (Pear Kids Art Admin System)

> 🎨 专业、优雅、极简线框设计系统的少儿美术教务考勤、课时积分商城与财务课消管理工作台。

---

## 🌟 核心功能特性

### 1. 📋 考勤大表 (Attendance Matrix)
- **课题主题与上课日期双列锁定**：支持左右平滑滑动，大表在任意设备上浏览自然。
- **学员打卡状态**：一键标记 到课 (消1节)、未到、请假、放假 等多种考勤状态。
- **快捷操作**：支持修改课题内容、单独补课消课、撤销考勤与数据回滚。

### 2. ⏳ 课时与积分排行榜 (Student Points & Ranking)
- **在读小艺术家总榜**：剩余课时预警、累计消课统计与画币积分池。
- **画币积分激励系统**：课堂表现奖励、全班积分分发、积分商城礼物兑换与明细流水留痕。

### 3. 🏫 班级管理与学员名册 (Class & Student Roster)
- **班级维度管理**：班级容量满载率、上课时段、主讲老师与二级班级详情页。
- **学员个人全景成长档案**：专属学员档案、剩余课时、学费充值流水与考勤成长履历。

### 4. 💰 财务与课消管理中心 (Finance & Consumption Center)
- **4 维核心财务 KPI**：本月收费入账、本年累计营收、机构累计总营收、待续费预估收入。
- **教学课消统计系统**：基于具体考勤信息实时汇总月度/周度/班级/学员 4 维教学消课产值与出勤率。
- **多维流水审计**：学员收费充值明细、课时变动总账、积分礼物流水、一键导出 CSV 报表与电子收据打印。

## 🚀 快速启动

本项目为纯前端轻量化架构，无需复杂的构建环境，直接在浏览器中打开即可使用：

1. **克隆仓库**：
   `ash
   git clone https://github.com/cenzuo2023-jpg/pear-kids-art-system.git
   cd pear-kids-art-system
   `

2. **本地启动**：
   可以直接双击打开 index.html，或使用 Python 启动本地轻量服务器：
   `ash
   python -m http.server 3000
   `
   随后在浏览器访问 http://localhost:3000。

## 🛠️ 技术栈
- **Vue 3** (Composition API)
- **Tailwind CSS** + 自定义 Wireframe 极简线框设计系统
- **FontAwesome 6** 图标库
- **LocalStorage / JSON** 数据本地持久化与一键备份还原
